# dsh-tech-stock-watch

盯住 A 股科技板块的成分股，盘中出现异动就主动推进当前会话。

不是行情面板，是**告警器**：你不问，它也会开口。

## 盯什么

股票池按板块自动取成分，每天盘中自动重建，新股和调仓不用手抄代码。默认 8 个板块：

半导体产业 · 芯片概念 · 人工智能 · 国产软件 · 存储器 · 光通信 · 共封装光模块(CPO） · 机器人概念

去重后约 860 只，按当日成交额排序截断到 600 只，保证轮询频率。

## 什么时候开口

| 规则 | 默认阈值 | 说明 |
| --- | --- | --- |
| 涨跌幅 | ±3% | 单边涨跌超过阈值 |
| 急拉 / 跳水 | 90 秒内 ±1.5% | 用连续快照自算，不等一天累计 |
| 放量 | 量比 ≥ 2.5 且涨跌 ≥ 1%；或换手 ≥ 10% 且涨跌 ≥ 2% | 资金进场的先兆 |
| 涨停 / 跌停 | 触及涨跌停价 | 每只每天只报一次 |
| 炸板 | 涨停打开 | 打开时报一次 |
| 板块异动 | 20 秒内涨跌幅变化 ≥ 1.5 个百分点 | 板块级 |
| 板块资金 | 20 秒内主力净流入变化 ≥ 5 亿 | 板块级 |
| 个股资金 | 主力净流入增加 ≥ 5000 万 | 新浪日级累计值的增量 |

降噪规则：

- 启动后 30 秒预热，只建基线不推送——盘中重启不会把全池既有涨幅一次性刷屏；
- 同一只票同类异动 10 分钟冷却；
- 两次推送至少间隔 20 秒，期间异动合并进下一条；
- 一轮同类异动超过 5 只时合并成一条群体提示（"科技股 449 只同向异动，代表：…"），涨跌停这类离散信号逐条保留前 3 只 + 汇总；
- 一轮最多 12 条，队列最多 30 条。

## 数据从哪来

全部是公开免费接口，无需 key：

- **腾讯 `qt.gtimg.cn`**：批量个股快照，含量比、换手、涨跌停价、报价时间戳（GBK 编码）；
- **腾讯 `proxy.finance.qq.com`**：概念板块排行（含板块涨跌幅、涨速、主力净流入）与板块成分（含个股涨速、量比、换手）；
- **新浪 `MoneyFlow.ssl_qsfx_zjlrqs`**：个股主力净流入。

实测记录（2026-11，本机）：东方财富 push2 被网络侧拒绝，`curl` 与 Node 都连不上，只有走代理的 web_fetch 能取到，所以不作为数据源。腾讯与新浪直连正常。

## 装

插件是一个 DSH bundle。**只能装进 Web 版 profile**：它要用 `webServer` 服务做数据转发，还要注册客户端 slot（`sidebar.panellist`、`main`、`conversation.composer.dock`）。装到 headless / CLI / ACP 这类没有浏览器的 profile 上会一直停在“等待服务”，工具也不会出现。

**从 GitHub 装**（发给别人用这个）：

```json
{
  "dependencies": {
    "dsh-tech-stock-watch": "github:meiwanmeiliaola/dsh-tech-stock-watch"
  },
  "dsh": {
    "profile": {
      "bundles": ["dsh-tech-stock-watch"]
    }
  }
}
```

**从本地目录装**（改代码即时生效）：

```json
"dsh-tech-stock-watch": "link:D:/ai_project/diy-plug-in-A"
```

然后四步：

1. 在该 profile 下 `pnpm install`
2. 重启 DSH
3. 刷新页面（客户端模块需要重新注入）
4. 在对话里说「开始盯盘」，或点左栏「科技股」图标

## 从插件市场装

插件市场按索引列举可安装的 bundle。在 profile 的 `cordis.patch.yml` 里追加这个索引：

```yaml
- id: plugin-market
  name: "@deepseek-ai/dsh-plugin-market"
  config:
    indexes:
      - https://meiwanmeiliaola.github.io/dsh-tech-stock-watch/index.json
```

重启后打开「插件市场」，能看到「科技股盘中监听」，点安装即可。索引文件在仓库的 `docs/index.json`，由 GitHub Pages 托管。

索引是未签名的：能搜到只代表你信任了那个索引地址，不代表官方验证。

**网络要求**：行情、分时、K 线都由本机 host 转发到腾讯，机器需要能访问 `qt.gtimg.cn`、`proxy.finance.qq.com`、`web.ifzq.gtimg.cn`。连不上时页面顶部会显示“分时已取 X/20 只”，并给出失败原因。

## 用

工具 `tech_watch`：

| 动作 | 作用 |
| --- | --- |
| `start` | 开始监听，异动推送到当前会话（推送目标就是调用它的会话） |
| `stop` | 停止 |
| `status` | 股票池大小、轮询节奏、累计命中与推送数 |
| `scan` | 立刻全池扫一遍，返回当前最强异动，不开启持续监听 |
| `test` | 发一条测试推送，确认链路通 |

推送目标不写死：任何一次调用都会把它刷新成当前会话。换会话之后告警会跟着走，不会一直打在旧会话上。

推送消息在对话里会以一条消息的形态出现（`source.kind` 是 `tech-stock-watch`），因为它要唤醒会话才能让你看见。看到 `[科技股异动]` 开头的消息，就是监听器在说话。

典型对话：

> 你：帮我盯着科技股，有异动告诉我
> 我：（调用 `tech_watch start`）已开始监听，异动会推送到当前会话…

之后盘中会自己冒出这样的消息：

```
[科技股异动] 2026-11-20 10:32:05
【急拉】寒武纪(688256)（+3.2%） 60 秒内 +1.8%，现价 920.00
【涨停】超声电子(000823) 封板 18.51
【跌幅异动】科技股 449 只同向异动，代表：阿石创 -17.2%、横河精密 -15.5%
```

## 配置

在 profile 的 `cordis.patch.yml` 里给这个条目加 `config`：

```yaml
- id: tech-stock-watch
  name: dsh-tech-stock-watch
  config:
    maxSymbols: 400
    boards:
      - 半导体产业
      - 人工智能
      - 国产软件
    thresholds:
      changePct: 5
      speedPct: 2
      volumeRatio: 3
```

可配项见 `src/config.js`；`thresholds` 单独合并，其余字段浅覆盖。

## 延迟与边界

- **理论延迟**：活跃股 5 秒一轮；全池 600 只分 6 片、每片 3 秒，一轮约 18 秒；板块 20 秒；个股资金 60 秒。
- 这是**秒级轮询的快照**，不是逐笔 Level-2 推送。公开免费通道拿不到逐笔和十档盘口，做高频不够，看异动够。
- 免费接口没有 SLA，可能限频或改字段。请求失败只记一次错误、不中断监听；休市和节假日靠「报价时间戳是否为今天且在 10 分钟内」自动静默。
- 交易时段按本机时间判断（09:10–11:35、12:55–15:10）；部署在非东八区机器上需要自行调整 `sessionWindows`。
- 个股主力净流入是新浪的**日级累计值**，用两次采样的差值近似「盘中突变」，不是逐笔资金流。
